## 📖 Overview

`@noverojava/libsignal-node` is a Signal Protocol implementation for Node.js based on the original Signal Protocol JavaScript ecosystem.

It provides cryptographic session functionality for applications requiring secure communication and encrypted session management.

---

## ✨ Features

- 🔐 Secure session management
- 🔑 PreKey support
- ✍️ Signed PreKey support
- 🪪 Identity key management
- 🔄 Session state management
- 🛡️ Forward secrecy
- 📦 PreKey Bundle support
- 💬 PreKey Signal Message support
- ⚡ Node.js support
